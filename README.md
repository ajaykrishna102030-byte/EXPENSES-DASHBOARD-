# EXPENSES-DASHBOARD-
# Expenses Dashboard (Excel + VBA)

An automated company expense-tracking dashboard built in Excel, using a macro-driven pipeline to turn raw transaction data into a live visual dashboard with KPIs and charts.

## 📁 File

- `EXPENSES_DASHBOASD_USING_EXCEL.xlsm` — macro-enabled Excel workbook (contains VBA)

## 📊 Overview

- **Records:** 415 expense transactions
- **Period:** January – December 2025
- **Currency:** INR (₹)
- **Departments:** Sales, Engineering, Marketing, HR, Finance, Operations
- **Categories:** Software, Marketing, Office Supplies, Equipment, Consulting, Travel, Utilities, Training
- **Payment Methods:** Cash, Credit Card, Cheque, Bank Transfer

## 🗂️ Workbook Structure

| Sheet | Purpose |
|---|---|
| **Data** | Raw transaction table (`tblExpenses`) — Expense ID, Date, Department, Category, Description, Amount, Payment Method, Approval status, Budget Allocated/Remaining, Vendor, Invoice Number, Month |
| **Pivot** | PivotTable summarizing expenses by department, category, and approval status |
| **Dashboard** | Visual report with KPIs and charts, auto-generated by macro |

## 📈 Dashboard Contents

**KPIs** (calculated live via `GETPIVOTDATA`):
- Total Expenses
- Total Budget Allocated
- Total Budget Remaining
- Expense Count
- Approval Rate
- Average Expense Amount

**Charts:**
1. Expense by Department (Bar)
2. Expense by Category (Doughnut)
3. Monthly Trend (Line)
4. Budget vs Actual (Bar)
5. Payment Method Breakdown (Bar)

## ⚙️ Automation

The workbook includes a VBA macro (`Module1.BuildExpensesDashboard`) that programmatically rebuilds the dashboard — refreshing the pivot table, repositioning charts, and reformatting KPIs — instead of relying on a static, manually-built layout.

To run it: open the workbook, enable macros, then `Alt + F8` → `BuildExpensesDashboard` → Run.

## 🚀 Getting Started

1. Download/clone the repo.
2. Open `EXPENSES_DASHBOASD_USING_EXCEL.xlsm` in Excel (macros must be enabled).
3. Edit or extend data in the **Data** sheet.
4. Re-run `BuildExpensesDashboard` (or refresh the Pivot manually) to update the Dashboard.

## ⚠️ Notes
